Community IoT Scale

Read, tare and zero a compatible MT-SICS scale from Odoo POS.

What it adds

Configure a scale per POS, read the latest stable weight and let the cashier confirm before applying it to the selected product line.

Requirements

Odoo 19 Community, Community IoT Box 19.0 and an agent announcing scale_read_v1 and scale_control_v1. Odoo.sh and on-premise are supported.
