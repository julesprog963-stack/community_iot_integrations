Community IoT ZPL

Send Zebra labels through the Community IoT queue with bounded, retryable jobs.

What it adds

Create a label-printer configuration, send ZPL test labels and print custom ZPL with up to ten independent copies.

Requirements

Odoo 18 Community, Community IoT Box 18.0 and an agent announcing zpl_print_v1. Odoo.sh and on-premise are supported.
